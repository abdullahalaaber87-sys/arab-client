# Arab Client

**Minecraft 1.21.11 Fabric Utility Client**  
Rebranded & fully updated from Anubis (now Arab).  
Click GUI: **RIGHT_SHIFT**  
Clean UI • Interactive HUD Settings • 6 Themes including **Arab Nebula**

### Features (exact list from spec)
- Combat: Aim Assist, Anchor Aura, Crystal Aura, Triggerbot, Kill Aura, etc. (full 16 listed)
- Misc, Donut, Render, Movement, Base Raid, Visuals, Arab Client (HUD + 7 more)
- Discord Presence, Interactive HUD Settings Panel (right-click), 6 themes (Halloween, Borealis, Nebula, Arab, Frost, Crimson)

**Build:** `./gradlew build`  
**Install:** Drop `arabclient-1.0.0.jar` into `mods` folder.
